# luminescence

Docker image of the R packages [**RLumShiny**](https://github.com/R-Lum/RLumShiny), [**gammaShiny**](https://github.com/crp2a/gammaShiny) and [**Al2O3AnalysisApp**](https://github.com/crp2a/Al2O3_AnalysisApp).

## Tags

```
docker pull ghcr.io/crp2a/luminescence:latest
```

```
docker run ghcr.io/crp2a/luminescence:latest
```

## Container Registry

```
docker login ghcr.io
```

```
docker build --no-cache -t ghcr.io/crp2a/luminescence:latest .
```

```
docker push ghcr.io/crp2a/luminescence:latest
```
